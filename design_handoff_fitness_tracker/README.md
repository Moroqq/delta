# Handoff: Фитнес-трекер с ИИ — «Spatial Glass»

## Обзор
Мобильное приложение — фитнес-трекер с ИИ-ассистентом. 4 раздела (таб-бар): **Тело** (метрики InBody), **Диета** (дневник питания + план), **Тренировки** (список / активная тренировка / прогресс упражнения), **ИИ-чат**. Визуальный стиль — «Spatial Glass»: тёмный тёплый фон с анимированными световыми пятнами, прозрачные стеклянные карточки со светлой верхней кромкой, свечение (glow) вместо цветной заливки для акцентов.

## О файлах дизайна
Файлы в этом пакете — **дизайн-референсы, созданные в HTML** (интерактивный прототип), а не production-код. Задача: **воссоздать эти экраны в среде целевой кодовой базы** (React Native, Flutter, SwiftUI, Kotlin/Compose и т.д.) с использованием её паттернов и библиотек. Если среды ещё нет — выберите наиболее подходящий фреймворк для мобильного приложения и реализуйте дизайн в нём. HTML-файлы нельзя переносить напрямую; используйте их как точную визуальную и поведенческую спецификацию.

Открыть прототип: `Фитнес-трекер v4.dc.html` в браузере (рядом должны лежать `support.js` и `android-frame.jsx` — служебные файлы прототипа, не часть дизайна).

## Fidelity
**High-fidelity (hifi).** Финальные цвета, типографика, отступы, тени и анимации. UI следует воспроизводить пиксель-точно (значения ниже и в исходнике прототипа).

## Дизайн-токены

### Цвета
- Фон экрана: градиент `linear-gradient(180deg, #221C15 0%, #171310 48%, #120F0A 100%)`
- Акцент (`--fit-accent`): `#F0E6D6` (тёплый кремовый). Тюнинг-варианты: `#F3D9A6`, `#E2E8E0`
- Основной текст: `#F2EFE8`
- Вторичный текст: `rgba(255,255,255,0.5)` — подписи; `0.45` — мелкие; `0.6–0.78` — описания
- Текст на светлых кнопках: `#1B1710`
- Стекло карточек: `rgba(46,40,33,0.30)` … `rgba(48,42,34,0.34)` + `backdrop-filter: blur(22–26px) saturate(1.4)`
- Оверлеи (таймер/шит): `rgba(48,42,34,0.55)` / `rgba(50,44,36,0.58)`, blur 30–40px
- Светлая кнопка (primary): `linear-gradient(180deg, #F4EAD6, #F0E4CD)`; «сияющая» версия (CTA плана): `linear-gradient(180deg, #FAF2E2, #EBDCC2)` + glow `0 0 28px rgba(240,230,214,0.28)`
- Разделители: `rgba(255,255,255,0.06–0.09)`

### Ключевая формула «стекла» (карточка)
```
background: rgba(46,40,33,0.30);
backdrop-filter: blur(24px) saturate(1.4);
border-radius: 22–30px;
box-shadow:
  inset 0 1px 0 rgba(255,243,219,0.28),   /* светлая кромка сверху */
  inset 0 0 0 1px rgba(255,243,219,0.07), /* тонкий контур */
  0 26px 60px -24px rgba(0,0,0,0.42);     /* глубокая мягкая тень */
```
Выделенная/активная карточка («Сейчас», «Сегодня»): кромка `0.42`, контур `rgba(240,230,214,0.30)`, наружный glow `0 0 30px -4px rgba(240,230,214,0.28)`, `transform: translateY(-2px)`.

### Атмосферный фон (за контентом, pointer-events:none)
3 размытых радиальных пятна тёплого света (`rgba(246,202,138,…)`, `rgba(240,196,138,…)`, `rgba(244,222,180,…)`), `filter: blur(38–42px)`, медленные keyframe-анимации масштаба/смещения (12–18 s, ease-in-out, infinite).

### Типографика
- Текст: **Golos Text** (400/500/600)
- Цифры и числовые значения: **Space Grotesk** (500/600/700) + `font-variant-numeric: tabular-nums`
- Шкала: заголовок экрана 22/600; заголовок подэкрана 19/600; hero-число 54/700 (Space Grotesk); число кольца 27/700; карточные значения 21–26/600; тело 13–15; kicker-подписи 11/500, `letter-spacing 1.2px`, uppercase, 50 % white; подписи осей 11
- Свечение крупных чисел: `text-shadow: 0 0 24px rgba(240,230,214,0.2)`

### Радиусы
Большие карточки 26–30 px; средние 22–24 px; вложенные плитки 16 px; инпуты 12 px; кнопки/пилюли/таб-бар 999 px; bottom sheet 32 px.

### Отступы
Паддинг экрана: `16px 18px`, нижний `104px` (под плавающий таб-бар). Gap между карточками 16 px, внутри сеток 10–12 px. Паддинг карточек `13–16px 15–18px`.

### Анимации
- `screenIn` — вход экрана: opacity 0→1, translateY(14px)+scale(0.985)→none, 0.35 s ease-out
- `cardIn` — вход карточки: translateY(18px), 0.4 s ease-out, стагер-задержки ~0.06 s на карточку
- `drawLine` — отрисовка линии графика через stroke-dashoffset (pathLength 600), 0.9 s `cubic-bezier(0.22,1,0.36,1)`
- `tabPop` — иконка активного таба: scale 0.82→1.14→1, 0.35 s spring `cubic-bezier(0.34,1.56,0.64,1)`
- `sheetUp` — bottom sheet снизу, 0.35 s `cubic-bezier(0.22,1,0.36,1)`
- Чекбоксы: заливка scale 0.4→1 (spring) + галочка через stroke-dashoffset
- Числа — анимированные каунтеры (ease-out cubic, 600–800 ms)
- Переключение метрики — интерполяция данных графика (550 ms ease-out cubic)
- Нажатия: `active → translateY(1–2px)` или `scale(0.92–0.97)`; лёгкая вибрация (navigator.vibrate(8))

## Экраны

### 1. Тело (`tab: body`)
- Заголовок «Тело» + дата справа.
- **Главная карточка метрики**: kicker-лейбл, hero-число 54 px + единица, справа пилюля дельты (стрелка + значение, акцентный цвет). График SVG 348×150: сглаженная кривая (Catmull-Rom→Bezier), градиентная заливка под линией (акцент 0.2→0), glow линии `drop-shadow(0 0 8px)`; пунктирные горизонтальные линии сетки; подписи месяцев Фев–Июл.
- **4 точки InBody** на кривой (x = 8/116/232/342): кружок r 4.5 (выбранный 7), заливка тёмная/акцент, обводка акцентом 2.5, glow; невидимая хит-зона r 16. Тап → bottom sheet замера.
- **Мини-карточки 2×2** (остальные 4 метрики из: вес, жир, мышцы, вода, висц. жир): лейбл, значение 26/600 + единица, дельта ▲/▼, спарклайн 64×22. Тап — метрика становится главной (график анимированно перетекает).
- Кнопка-стекло «+ Добавить замер InBody».
- **Bottom sheet замера**: скрим `rgba(0,0,0,0.45)` + blur 4px; карточка от краёв 8 px, radius 32; grabber 40×4; дата + вес 34/700; сетка 2×2 (жир %, мышцы кг, вода %, висц. жир ур.); строка с превью загруженного скриншота InBody.

### 2. Диета · День (`tab: diet, view: day`)
- Заголовок «Диета», справа ссылка «Мой план ›» (акцент, glow).
- **Карточка КБЖУ**: слева кольцо 132 px — трек `rgba(255,255,255,0.1)` 3 px, прогресс акцентом 3.5 px + широкая размытая копия (12 px, opacity 0.22, blur 11px) как glow; в центре съеденные ккал (каунтер) и «из 1 950 ккал». Справа 3 прогресс-бара (белки/жиры/углеводы): трек — тёмная канавка `rgba(0,0,0,0.28)` c inset-тенью, заполнение акцентом с glow (жиры opacity 0.65, углеводы 0.4), подписи «X / N г».
- **Приёмы пищи** (4 карточки): круглый чекбокс 30 px «съедено»; название + время (Space Grotesk); бейдж «Сейчас» на первом несъеденном (светлая пилюля, тёмный текст, glow) — карточка подсвечена; блюда; строка КБЖУ. Съеденные — opacity 0.55. Тап — аккордеон списка блюд: граммы + КБЖУ + пилюля «заменить». КБЖУ дня суммируются из отмеченных приёмов.
- **Задачи на день**: 3 чекбокс-строки, счётчик «N из 3», выполненные — приглушённый текст.
- Кнопка primary «Сканировать этикетку» (иконка камеры).

### 3. Диета · Мой план (`view: plan`)
- Кнопка «назад» (стеклянный круг 38 px) + заголовок.
- Карточка цели (подсвеченная): «Сушка · дефицит 500 ккал», 4 колонки целевых КБЖУ с разделителями (белки — акцентом).
- «Меню на неделю»: 7 строк Пн–Вс (текущий день — акцент с glow, остальные приглушены).

### 4. Тренировки · Список (`view: list`)

- Завершённая тренировка: иконка-галочка в круге, название, статистика, бейдж «Готово».
- **Сегодняшняя** (подсвеченная карточка): бейдж «Сегодня», список упражнений (название + инвентарь слева, схема 4×10 справа), кнопка «Начать тренировку».

### 5. Тренировки · Активная (`view: active`)

- Карточки упражнений: шапка (тап → экран прогресса) с мини-иконкой тренда; строки подходов: № · **input веса** (52 px) · «кг ×» · **input повторов** (38 px) · индикатор ▲ (акцент, если вес выше прошлого) · «прошлый раз: N кг × M». Инпуты — тёмные «канавки» `rgba(0,0,0,0.25)` с inset-тенью, radius 12.
- Внизу: «Завершить тренировку» (primary) + круглая кнопка таймера 50 px.
- **Оверлей таймера отдыха**: скрим blur 8px; карточка 270 px по центру; кольцо 150 px с обратным отсчётом (stroke-dasharray, transition 1s linear); время 36/700; кнопки «Сначала» / «Пауза|Продолжить|Ещё раз»; крестик закрытия. Вибрация по окончании.

### 6. Тренировки · Прогресс упражнения (`view: progress`)
- «Назад» + название, «прогресс рабочего веса · 7 недель».
- Карточка: текущий вес 40/700 + дельта «+N кг за 7 недель»; график 348×150 (ломаная по неделям Н1–Н7, точки stroke-linecap round 7 px с glow).
- 2 карточки: «Лучший результат», «Суммарный тоннаж».
- «Совет ИИ» — карточка со светящейся точкой и текстом (у каждого упражнения свой).

### 7. ИИ-чат · Пустое состояние (`tab: chat`)
- Центр: **вертикальный луч света** (тонкая линия 2.5 px + размытый ореол, анимация «дыхания» 5 s) со звездой-искрой внизу; «Чем помочь?» 26/600 с glow; подзаголовок.
- Поле ввода-пилюля: placeholder «Спросите о питании…», иконки фото и микрофона, светлая круглая кнопка отправки 40 px.
- 3 чипа-подсказки («Составь ужин на 600 ккал», «Почему вес встал?», «План на сегодня») — тап открывает диалог.

### 8. ИИ-чат · Диалог
- Шапка: аватар (светящаяся точка в стеклянном круге), «Ассистент / знает ваши замеры и цели», кнопка «+» (новый чат → пустое состояние).
- Сообщения: ассистент — слева, тёмное стекло, radius `22 22 22 8`; пользователь — справа, `rgba(240,230,214,0.13)`, radius `22 22 8 22`; вложение-изображение (этикетка) — карточка 170×120 над сообщением. Стагер-появление.
- Поле ввода внизу (как в пустом состоянии, компактнее).

### Плавающий таб-бар (все экраны)
Стеклянная пилюля по центру, bottom 16 px: `rgba(44,39,32,0.40)`, blur 32px saturate 1.5. 4 таба по 76 px: иконка 21 px stroke 1.6 + подпись 10 px. Активный: акцентный цвет + glow иконки + фон `rgba(255,255,255,0.08)` + анимация tabPop. Неактивный: `rgba(255,255,255,0.42)`.

## Интеракции и состояния
- Навигация: state-машина `tab` (body/diet/train/chat) + подвиды `dietView` (day/plan), `trainView` (list/active/progress), `chatStarted`, `selPoint` (bottom sheet), `timerOpen`.
- Смена таба сбрасывает подвиды и перезапускает входные анимации (стагер).
- Чекбоксы приёмов пищи пересчитывают кольцо ккал, бары БЖУ и бейдж «Сейчас» (первый несъеденный).
- Инпуты веса/повторов редактируемы; стрелка ▲ появляется, когда вес > прошлого.
- Тактильный отклик (лёгкая вибрация) на все тапы; паттерн [60,40,60] на финиш таймера.

## State management (минимум)
`tab, dietView, trainView, progressEx, metric, selPoint, expanded (id открытого приёма), eaten{}, done{} (задачи), sets[][] (вес/повторы), chatStarted, timerOpen/timerLeft/timerRun, goal`. Данные (метрики InBody, план питания, тренировка, история весов) в прототипе захардкожены — в реальном приложении приходят с бэкенда; ответы «Рекомендации ИИ» и чат — от LLM с контекстом пользователя.

Внешних ассетов нет: вся иконография — инлайн-SVG (stroke 1.5–1.8, round caps), графики — генерируемые SVG-пути. Шрифты — Google Fonts: Golos Text, Space Grotesk.

Отдельный анимированный тизер приложения, 24 с, вертикальный формат 1080×1920 (сторис/reels). Не экран приложения — маркетинговый ролик; при переносе в продакшн реализуется через видео-редактор/motion-инструмент (After Effects, Lottie/Rive и т.п.) либо остаётся как HTML/видео-файл для паблишинга, а не как код приложения.

Раскадровка:
- 0.0–2.7 с — интро: «AI Fitness» + слоган по центру на атмосферном фоне.
- 2.7–3.3 с — телефон в рамке Android поднимается снизу.
- 3.5–8.2 с — **01 · ТЕЛО**: карточка веса, число-каунтер 61.4→78.2 кг, отрисовка линии графика.
- 8.2–13.0 с — **02 · ДИЕТА**: кольцо ккал (каунтер до 1480), бары БЖУ, появление приёмов пищи.
- 13.0–18.0 с — **03 · ТРЕНИРОВКИ**: список подходов появляется построчно со стагером.
- 18.0–22.6 с — **04 · ИИ-ЧАТ**: диалог из 2 сообщений (вопрос/ответ ассистента).
- 22.8–24.0 с — аутро: логотип + слоган + кнопка «Скачать приложение».

Подписи-kicker и заголовки экрана всплывают синхронно с каждым сегментом (fade + translateY). Цвета, стекло-карточки, шрифты (Golos Text / Space Grotesk) и формулы теней — те же токены, что в разделе «Дизайн-токены» выше.
